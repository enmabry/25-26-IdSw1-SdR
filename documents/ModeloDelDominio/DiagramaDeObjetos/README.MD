## 🎯 Diagrama de Objetos del Sistema

El diagrama de objetos **complementa el diagrama de clases** mostrando **instancias específicas** de las clases en un **momento determinado del tiempo**. Proporciona una visión concreta de cómo las entidades del sistema interactúan en un escenario particular, facilitando la validación y comunicación de casos de uso específicos.
